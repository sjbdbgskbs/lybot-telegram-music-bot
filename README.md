# LyBot — Telegram Music Voice Chat Bot

بوت موسيقى مستقل لتليجرام، مبني ليعمل داخل الكروبات والمكالمات الصوتية.

## المزايا

- البحث عن الأغاني عبر YouTube وSoundCloud وBandcamp من خلال `yt-dlp`.
- فهم روابط YouTube وSoundCloud وSpotify وApple Music ومحاولة إيجاد نسخة تشغيل مناسبة.
- ترتيب النتائج حسب تطابق العنوان والفنان والمصدر والمدة.
- تشغيل الصوت الحقيقي داخل Group Voice Chat.
- قائمة تشغيل مستقلة لكل كروب.
- أزرار داخل الرسائل للتشغيل، الإيقاف المؤقت، الاستئناف، التخطي، الإنهاء، وعرض الطابور.
- أوامر عربية وإنجليزية متوافقة مع أسلوب بوتات الموسيقى الشائعة.
- إعدادات لكل كروب محفوظة في SQLite.
- تشغيل مباشر على Pella أو أي استضافة تدعم Python 3.11 وFFmpeg.

> ملاحظة مهمة: Telegram Bot API وحدها لا تدخل المكالمات الصوتية. لذلك يستخدم المشروع حساب Telegram مساعداً عبر MTProto/PyTgCalls. يجب إضافة الحساب المساعد إلى الكروب والسماح له بالانضمام للمكالمة.

## الأوامر

### التشغيل والبحث

- `/play <اسم الأغنية أو الرابط>` — بحث وتشغيل، أو أضف إلى الطابور.
- `/p <اسم الأغنية>` — اختصار `/play`.
- `/vplay <اسم الأغنية>` — اختصار تشغيل متوافق مع بوتات الفيديو القديمة، ويشغل الصوت فقط.
- `/song <اسم الأغنية>` — بحث وعرض أفضل النتائج دون تشغيل.
- `/search <اسم الأغنية>` — مثل `/song`.
- `/join` — دخول الحساب المساعد إلى المكالمة الحالية.

### التحكم

- `/pause` — إيقاف مؤقت.
- `/resume` أو `/continue` — استئناف.
- `/skip` أو `/next` — تخطي الأغنية الحالية.
- `/stop` أو `/end` — إيقاف وتفريغ الطابور.
- `/queue` أو `/playlist` — عرض الطابور.
- `/now` أو `/current` — الأغنية الحالية.

### المساعدة والإعدادات

- `/start`
- `/help`
- `/settings` — لوحة إعدادات الكروب داخل الرسالة.

الأوامر الحساسة مثل الإيقاف وتغيير الإعدادات تحتاج صلاحية مشرف. ويمكن تحديد ذلك من `/settings`.

## المتطلبات

- Python 3.11 أو أحدث.
- FFmpeg.
- Bot Token من @BotFather.
- Telegram API ID وAPI Hash من https://my.telegram.org.
- جلسة حساب Telegram مساعد. يمكن إنشاؤها من `scripts/generate_session.py`.
- الحساب المساعد عضو في الكروب، ويفضل منحه صلاحية إدارة المكالمات.

## التشغيل المحلي

```bash
cp .env.example .env
# عدّل القيم في .env
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

لا ترفع ملف `.env` أو أي ملف جلسة إلى GitHub.

## إنشاء جلسة الحساب المساعد

إذا لم تكن قيمة `TELEGRAM_USER_SESSION` جاهزة:

```bash
python scripts/generate_session.py
```

سيطلب السكربت رقم الهاتف، رمز تسجيل الدخول، وكلمة مرور التحقق بخطوتين إن وجدت. انسخ النص الناتج إلى متغير `TELEGRAM_USER_SESSION` في Pella فقط.

## التشغيل على Pella أو Docker

### Pella

1. ارفع المستودع.
2. اختر Python 3.11.
3. ثبّت FFmpeg من أدوات النظام أو استخدم صورة Docker.
4. أضف القيم الموجودة في `.env.example` كـ Secrets.
5. أمر التشغيل:

```bash
python bot.py
```

### Docker

```bash
docker compose up -d --build
```

## ملاحظات حقوق المحتوى

المشروع يبحث ويشغل المصادر العامة التي يسمح بها المصدر ومشغل الاستضافة. لا يتجاوز الحماية أو الاشتراكات ولا يخزن ملفات الأغاني بشكل دائم. استخدمه مع محتوى تملك حق تشغيله.
